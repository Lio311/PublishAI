# תוכנית עבודה ומפרט טכני מלא - מערכת AI לעריכת מאמרים אקדמיים

## 1. תקציר מנהלים (Executive Summary)
מערכת SaaS חכמה המקבלת מאמרים אקדמיים גולמיים (Word/PDF) ומעבירה אותם תהליך אוטומטי-למחצה (היברידי) בן 9 שלבים להפיכתם למאמרים מוכנים לפרסום בכתבי עת מובילים (Top-tier journals). המערכת מתבססת על סוכני AI מתמחים (Claude Opus/Sonnet) הפועלים בשרשרת, עם נקודות אישור (Approval Gates) מול המשתמש. 

## 2. חוויית משתמש (User Flow)
1. **הרשמה/התחברות:** המשתמש נכנס באמצעות Google (OAuth) או אימייל/סיסמה.
2. **העלאה (Drag & Drop):** המשתמש גורר קובץ Word או PDF למערכת.
3. **ראיון מקדים (Clarification):** סוכן AI מראיין את המשתמש באמצעות שאלות אמריקאיות קצרות להבנת דרישות כתב העת והאילוצים.
4. **תוכנית עבודה (Planning):** המערכת מציגה תוכנית ריוויזיה למאמר (חולשות, יעדים). **המשתמש מאשר**.
5. **סקירה וכתיבה (Execution):** המערכת עוברת על המאמר סקציה-אחר-סקציה (מבוא, שיטות, תוצאות וכו').
   * מוצג מסך Track Changes מתקדם (בדומה ל-Word).
   * **המשתמש מאשר/דוחה** שינויים לכל סקציה בנפרד.
6. **בדיקת איכות סופית (QA & Verification):** אישור סופי של התוצאה ובחינת "דוח ביקורת עמיתים מדומה".
7. **ייצוא:** קבלת קובץ Word/PDF סופי בפורמט התואם 1:1 למקור, בתוספת מכתב מקדים (Cover Letter).

## 3. ארכיטקטורה טכנולוגית (Tech Stack)
* **Frontend + Backend:** Next.js 14+ (App Router), TypeScript, Tailwind CSS
* **Hosting:** Vercel Pro ($20/mo) לתמיכה בזמני ריצה ארוכים (Timeout של 60-300 שניות).
* **Database & Storage:** Neon Postgres (Managed Serverless DB + Blob Storage לקבצים).
* **Authentication:** NextAuth.js v5 (Auth.js) - ניהול סשנים אובטח, התחברות גוגל.
* **Background Jobs & Orchestration:** Inngest - ניהול ה-Pipeline של סוכני ה-AI ברקע.
* **AI Models:** Claude 3.5 Sonnet (למשימות מהירות ואימות) ו-Claude 3.5 Opus (לכתיבה וניתוח מדעי עמוק).
* **Emails:** Nodemailer עם שרת SMTP חיצוני (Gmail / Amazon SES / SendGrid) לשליחת התראות.
* **Literature Search:** שילוב חינמי של PubMed, Semantic Scholar, ו-arXiv.

## 4. ארכיטקטורת סוכני ה-AI (The Agent Pipeline)
המערכת מורכבת מהסוכנים הבאים הפועלים בזה אחר זה:
1. **Clarification Agent (Sonnet):** חילוץ דרישות מהמשתמש לגבי כתב העת.
2. **Planning Agent (Opus):** סקירה כוללת של המאמר ותכנון הריוויזיה.
3. **Knowledge Agent (Sonnet):** חיפוש והעשרת רפרנסים מול מאגרי המידע האקדמיים.
4. **Scientific Review Agent (Opus):** סקירת עמיתים פנימית, חיפוש כשלים לוגיים ומתודולוגיים.
5. **Academic Writing Agent (Opus):** כתיבה מחדש, הסרת סממני "AI", התאמה לשפה מדעית מדויקת.
6. **Execution Agent (Opus):** ביצוע השינויים פיזית בטקסט (בפורמט Diff).
7. **QA Agent (Sonnet):** בקרת איכות על עקביות, שגיאות כתיב, הפניות לטבלאות ותמונות.
8. **Verification Agent (Sonnet):** יצירת דוח ביקורת עמיתים סימולטיבי ו-Cover Letter.
9. **Compilation Agent (Sonnet):** שילוב הטקסט חזרה לקובץ בפורמט המקורי (שמירה על עיצוב).

## 5. תוכנית עבודה ליישום (Phased Implementation)

### שלב 1: תשתיות ליבה ומסד נתונים (שבועות 1-3)
* הקמת פרויקט Next.js ב-Vercel (Pro).
* הגדרת סכמות Database ב-Neon Postgres (טבלאות למשתמשים, מאמרים, היסטוריית גרסאות).
* הגדרת NextAuth להתחברות משתמשים.
* פיתוח דף Dashboard ראשי להעלאת קבצים (Drag & Drop) עם תצוגת סטטוסים.
* הקמת מנגנוני חילוץ טקסט (מ-Word ומ-PDF).

### שלב 2: פיתוח מנוע הסוכנים (שבועות 4-7)
* פיתוח ספריית התקשורת מול Anthropic (Claude API) עם טיפול ב-Rate limits.
* פיתוח תשתית התהליכים ברקע באמצעות Inngest.
* יצירת 9 הסוכנים (פיתוח הפרומפטים והלוגיקה לכל אחד).
* שילוב ה-APIs החינמיים של PubMed ו-Semantic Scholar.

### שלב 3: ממשק מתקדם וחוקי כתבי עת (שבועות 8-10)
* פיתוח מסך Track Changes המאפשר קבלה/דחייה של שינויים פר-סקציה.
* הקמת מאגר מידע ראשוני של חוקי כתבי עת מובילים (מגבלות מילים, סגנון ציטוט).
* פיתוח מנוע להחזרת הטקסט המעובד חזרה לקובץ Word/PDF סופי תוך שמירה על העיצוב (Formatting).

### שלב 4: התראות, אבטחה ופינישים (שבועות 11-12)
* אינטגרציה של Nodemailer לשליחת התראות במייל ("המאמר שלך עבר ריוויזיה וממתין לאישור").
* הטמעת בדיקות Plagiarism וזיהוי "שפת AI" בסיסיות.
* מנגנון אבטחת חשבונות (Account Security).
* בדיקות עומס ובדיקות קצה לקצה (QA).

### שלב 5: תוכניות לעתיד (Post-Launch)
* הגשה אוטומטית (Auto-Submission) לכתבי עת בחיבור עם פרטי המשתמש.
* טיפול אוטומטי בהערות Reviewers שהתקבלו במייל והגשה מחדש (Resubmission).
